SkillCraft Technology Internship Task 03 project – Tic Tac Toe Web Application 🎯

For this task, I developed an interactive Tic Tac Toe game that allows two players to enjoy a classic game experience right in the browser!


✅ Playable two-player mode (X and O)

✅ Real-time winner detection

✅ Option to restart and play again


✨ Key Features:

✔ Clean and modern game board UI

✔ Highlighting of the winning combination

✔ Smooth animations and transitions

Fully responsive across devices


💡 Learning gained: 
Deepened my understanding of JavaScript logic, event handling, and conditional programming while focusing on interactive UI design.
